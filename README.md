# Sales Data Analysis and Business Intelligence Dashboard

## Project Overview
This project analyzes sales data using Python, SQL, and Excel to identify sales trends, product performance, and business insights.

## Technologies Used
- Python
- SQL (MySQL)
- Microsoft Excel

## Project Features
- Created and managed a sales dataset using Python.
- Analyzed sales data using SQL queries.
- Calculated total sales and product quantities.
- Identified top-performing products and categories.
- Created an Excel dashboard with charts and visualizations.
- Presented business insights in an easy-to-understand format.

## Key Results
- Total Sales: ₹3,57,500
- Total Records: 10
- Top Sales Product: Laptop
- Highest Sales Category: Electronics

## Learning Outcomes
- Data cleaning and analysis using Python.
- SQL queries and database operations.
- Excel data visualization and dashboard creation.
- Understanding sales performance and business insights.
